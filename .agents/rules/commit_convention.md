# Git Commit Versioning Rule

Whenever making a git commit:
- Use semantic version tags in the commit message: `V-1.1`, `V-1.2`, `V-1.3`, etc.
- Current base version: `V-1.0` (Production Baseline).
- Format: `V-1.X: <brief summary of update>` or simply `V-1.X`.
- Increment the minor version with each consecutive update pushed to GitHub.
